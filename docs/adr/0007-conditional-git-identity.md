# ADR-0007: Identité git conditionnelle par répertoire (pro/perso)

L'identité Git par défaut est **personnelle** (`ekodev <ekoledev@gmail.com>`, clé SSH `github-personal`). L'identité **pro** (`deessaka.samuel@ejara.africa`, clé `github-work`) s'applique uniquement sous `~/workspace/ejara/**` via `[includeIf "gitdir:~/workspace/ejara/"]` dans `.gitconfig` → fichier dédié `.gitconfig-work`. Les URLs de remotes sont réécrites (`git@github.com:`/`https://github.com/` → `git@github-personal:` ou `git@github-work:`) selon le contexte. Raison : l'email pro ne doit jamais fuiter dans des commits perso ni l'inverse ; deux clés SSH distinctes existent déjà et sont sélectionnées automatiquement par répertoire. Contre-option rejetée : une seule identité globale pro (risque de commits pro par erreur) ou config SSH par-repo manuelle (non maintenable sur 6+ repos).
